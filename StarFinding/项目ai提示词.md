### 📋 复制以下内容发送给墨刀 AI：

**【项目全局设定】**

请帮我设计一款名为“寻星 2.0 —— 校园互助与失物招领综合平台”的高保真原型。

- **架构体系**：包含“面向全校学生的移动端（微信小程序）”和“面向校方管理员/辅导员的 PC 端（后台管理系统）”。两个终端数据互通。
    
- **设计风格**：年轻化、扁平化、注重温暖感与社区感。
    
- **主色调**：建议采用“校园蓝”（代表信任、严谨）搭配“活力橙”或“暖黄”（代表互助、温暖）。大面积留白，保证信息清晰。UI 组件需符合微信原生规范及现代 Web UI 规范（如 Ant Design）。
    

**【第一部分：移动端（微信小程序）页面需求】**

请设计以下 5 个核心页面，要求包含底部全局 TabBar（首页、荣誉墙、发布、消息、我的）：

**1. 首页：互助信息大厅（融合模块 1：互助大厅）**

- **顶部**：搜索框（支持关键字搜索物品/标题）+ 轮播图（展示校园防骗指南、优秀互助事迹、最新公告）。
    
- **金刚区/分类 Tab**：醒目的三个切换选项卡：“寻物启事”、“失物招领”、“万能求助”。
    
- **内容区**：采用双列瀑布流卡片展示。每个卡片包含：物品大图、一句话标题、分类标签、**发布者学号昵称**、发布时间。卡片角落需有状态 Tag（如“待解决”蓝色，“已解决”绿色）。
    
- **悬浮组件**：右下角放置一个醒目的“+”号圆形悬浮按钮，作为快速发布的快捷入口。
    

**2. 帖子详情页（融合模块 2：线索留言 + 模块 3：举报 + 模块 4：信誉积分 + 模块 5：赛博锦旗）**

- **用户信息栏**：顶部展示发布者头像、昵称、**醒目的“信誉分”标签（如：100分 极好）**、发布时间。
    
- **正文区**：大图轮播展示（支持点击放大）、帖子标题、详细描述文本、丢失/捡到地点标签、分类标签。
    
- **操作交互区**：带有“分享”、“一键复制联系方式”按钮。特别设计一个**“举报”按钮（图标+文字）**。
    
- **互动区（线索留言板）**：下方为线索留言列表。需要体现时间轴概念。如果是发布者回复，需要有“车主/楼主”标识。
    
- **底部工具栏（特殊状态流转）**：
    
    - _普通状态下_：吸底输入框（写留言），右侧发送按钮。
        
    - _如果是发布者本人查看且状态为待解决时_：底部多一个醒目的绿色按钮“已找到/已解决”。
        
    - _点击“已解决”后触发的交互原型_：弹窗提示“是否解决并送出赛博锦旗？”确认后，跳转到模块 5 的锦旗设计页，或直接展示“锦旗已送出”的动画效果。
        

**3. 校园荣誉墙页（融合模块 5：赛博锦旗/感谢信）**

- **顶部**：横向滚动展示“校园互助之星”排行榜（头像+昵称+累计积分）。
    
- **内容区**：瀑布流或列表展示最近收到的感谢信/赛博锦旗。每个卡片设计成一张精美的电子锦旗样式（上面有“感谢XX同学拾金不昧/乐于助人”等文字），UI 风格要体现荣誉感和温馨感。
    

**4. 发布帖子页（表单提交 + 模块 4 积分校验预警）**

- **顶部**：类型选择（胶囊样式的单选按钮：寻物/招领/求助）。
    
- **核心表单**：标题输入框、详细描述多行文本框、地点选择器/输入框、联系方式输入框、物品分类下拉选择框（电子产品、证件、书籍等）。
    
- **多媒体上传**：图片上传九宫格组件（带有“+”号的上传占位图，支持传多图）。
    
- **风控预警（原型暗示）**：表单下方展示一段小字提示：“发布虚假信息将扣除 20 信誉分。您当前积分为 98 分。”
    
- **底部**：悬浮吸底的“立即发布”大按钮。
    

**5. 个人中心页（我的）（融合模块 4：信誉积分 + 模块 5：我的感谢）**

- **顶部用户信息**：用户头像、昵称、学号。醒目位置放置一个**信誉积分展示组件（例如一个仪表盘或大型进度条，直观展示 100 分，并带有“表现极好”的评级文字）**。
    
- **数据统计栏**：横向排列的四个数字指标：已发布、已帮助、收到锦旗、违规次数。
    
- **功能列表区**：采用带图标的列表项排布，包含：“我的发布”、“我的留言”、“我收到的感谢”、“我发出的举报”、“积分明细接口卡（展示积分变动记录，如 +10, -20）”、“退出登录”。
    

**【第二部分：PC 端（后台管理系统）页面需求】**

请采用经典的左侧深色菜单栏、顶部顶栏、右侧白色内容区的后台布局设计以下 3 个核心页面：

**1. 首页：校园互助数据大屏（控制台）（融合模块 6：数据大屏）**

- **顶部数据卡片栏**：四个大型数字卡片（全校累计互助次数、今日新增发帖量、累计找回物品数、待处理风控举报）。
    
- **图表核心区**：左侧展示一个酷炫的“近七天帖子类型趋势分析”折线图（ECharts 风格）；右侧展示一个“各学院‘活雷锋’积分排行榜”的柱状图。
    
- **下方状态区**：展示一个简单的饼图“当前平台物品分类占比”以及一个列表“最新 5 条实时发帖滚动展示”。
    

**2. 帖子综合管理台（Table 表格页 + 融合模块 3：审核下架 + 模块 4：信誉分展示）**

- **顶部筛选区**：包含发帖人学号搜索、帖子状态下拉框（待解决/已解决/已强制下架）、帖子类型下拉框、查询和重置按钮。
    
- **数据表格区**：关键列包括：帖子ID、缩略图、标题、类型、发布人学号、**发布人信誉分**、发布时间、状态（用不同颜色 Tag 标签展示）。
    
- **操作列**：提供“查看详情”文本按钮。当帖子状态不为已下架时，额外提供一个醒目的红色“**强制下架**”按钮。
    

**3. 风控审核与举报中心（融合模块 3：风控审核 + 模块 4：黑名单管理）**

- **顶部筛选**：处理状态下拉框（待审核/已驳回/已处理）。
    
- **数据表格**：专注于展示被举报的内容。关键列包括：被举报帖子ID、标题、举报人学号、被举报人学号、举报原因类型、举报时间、状态。
    
- **操作交互原型**：点击“审核”操作时，屏幕右侧滑出一个大型抽屉（Drawer）。抽屉内左侧展示该帖子的详细图文内容，右侧展示举报详情及图片证明。底部包含两个操作按钮组：“驳回举报”；“**确认违规并下架**”。
    
- **关联动作预警**：确认违规下架按钮下方有小字提示：“执行此操作将自动扣除该帖子发布者 20 信誉分，积分低于 60 将拉入黑名单。”

## 1. 排序算法

### 1.1 快速排序 (Quick Sort)
**核心思想**：分治。注意边界条件，通常取中间值 `x = q[l + r >> 1]` 配合 `j` 划分能避免死循环。
```cpp
void quick_sort(int q[], int l, int r) {
    if (l >= r) return;

    int i = l - 1, j = r + 1, x = q[l + r >> 1];
    while (i < j) {
        do i ++ ; while (q[i] < x);
        do j -- ; while (q[j] > x);
        if (i < j) swap(q[i], q[j]);
    }
    
    quick_sort(q, l, j);
    quick_sort(q, j + 1, r);
}
````

### 1.2 归并排序 (Merge Sort)

**核心思想**：分治合并。稳定排序，常用于求逆序对的数量。需要额外数组 `tmp`。

C++

```
int tmp[N];

void merge_sort(int q[], int l, int r) {
    if (l >= r) return;

    int mid = l + r >> 1;
    merge_sort(q, l, mid);
    merge_sort(q, mid + 1, r);

    int k = 0, i = l, j = mid + 1;
    while (i <= mid && j <= r)
        if (q[i] <= q[j]) tmp[k ++ ] = q[i ++ ];
        else tmp[k ++ ] = q[j ++ ];

    while (i <= mid) tmp[k ++ ] = q[i ++ ];
    while (j <= r) tmp[k ++ ] = q[j ++ ];

    for (i = l, j = 0; i <= r; i ++, j ++ ) q[i] = tmp[j];
}
```

## 2. 二分查找

### 2.1 整数二分

**口诀**：有加必有减。如果更新是 `l = mid`，计算 `mid` 时必须 `+ 1`。

C++

```
bool check(int x)  // 检查x是否满足某种性质

// 区间 [l, r] 被划分成 [l, mid] 和 [mid + 1, r] 时使用：
int bsearch_1(int l, int r) {
    while (l < r) {
        int mid = l + r >> 1;
        if (check(mid)) r = mid;    // check()判断mid是否满足性质
        else l = mid + 1;
    }
    return l;
}

// 区间 [l, r] 被划分成 [l, mid - 1] 和 [mid, r] 时使用：
int bsearch_2(int l, int r) {
    while (l < r) {
        int mid = l + r + 1 >> 1;
        if (check(mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
```

### 2.2 浮点数二分

不需要考虑整除的边界问题，一般保留的位数决定精度。

C++

```
bool check(double x)  // 检查x是否满足某种性质

double bsearch_3(double l, double r) {
    const double eps = 1e-6;   // eps 表示精度，取决于题目对精度的要求，一般比保留位数多两位
    while (r - l > eps) {
        double mid = (l + r) / 2;
        if (check(mid)) r = mid;
        else l = mid;
    }
    return l;
}
```

## 3. 高精度

使用 `std::vector<int>` 逆序存储数字（个位在 `A[0]`）。

### 3.1 高精度加法 ($A + B$)

C++

```
// C = A + B, A >= 0, B >= 0
vector<int> add(vector<int> &A, vector<int> &B) {
    if (A.size() < B.size()) return add(B, A);
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size(); i ++ ) {
        t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);
        t /= 10;
    }
    if (t) C.push_back(t);
    return C;
}
```

### 3.2 高精度减法 ($A - B$)

C++

```
// 比较A和B的大小：A >= B 返回 true，否则返回 false
bool cmp(vector<int> &A, vector<int> &B) {
    if (A.size() != B.size()) return A.size() > B.size();
    for (int i = A.size() - 1; i >= 0; i -- )
        if (A[i] != B[i])
            return A[i] > B[i];
    return true;
}

// C = A - B, 满足 A >= B, A >= 0, B >= 0
vector<int> sub(vector<int> &A, vector<int> &B) {
    vector<int> C;
    for (int i = 0, t = 0; i < A.size(); i ++ ) {
        t = A[i] - t;
        if (i < B.size()) t -= B[i];
        C.push_back((t + 10) % 10);
        if (t < 0) t = 1;
        else t = 0;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back(); // 去掉前导0
    return C;
}
```

### 3.3 高精度乘低精度 ($A \times b$)

C++

```
// C = A * b, A >= 0, b >= 0
vector<int> mul(vector<int> &A, int b) {
    vector<int> C;
    int t = 0;
    for (int i = 0; i < A.size() || t; i ++ ) {
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }
    while (C.size() > 1 && C.back() == 0) C.pop_back(); // 防止b为0的情况
    return C;
}
```

### 3.4 高精度除以低精度 ($A \div b$)

C++

```
// A / b = C ... r, A >= 0, b > 0
vector<int> div(vector<int> &A, int b, int &r) {
    vector<int> C;
    r = 0;
    for (int i = A.size() - 1; i >= 0; i -- ) {
        r = r * 10 + A[i];
        C.push_back(r / b);
        r %= b;
    }
    reverse(C.begin(), C.end()); // 因为除法是从高位开始算的，存入C是从高位到低位，需要翻转
    while (C.size() > 1 && C.back() == 0) C.pop_back();
    return C;
}
```

## 4. 前缀和与差分

**注意**：数组下标务必从 1 开始，避免 `i-1` 越界。

### 4.1 一维前缀和

C++

```
// S[i] = a[1] + a[2] + ... a[i]
// 求区间 [l, r] 的和：
int sum = S[r] - S[l - 1];
```

### 4.2 二维前缀和

C++

```
// 求前缀和矩阵：
S[i][j] = S[i - 1][j] + S[i][j - 1] - S[i - 1][j - 1] + a[i][j];

// 求左上角为(x1, y1), 右下角为(x2, y2)的子矩阵和：
int sum = S[x2][y2] - S[x1 - 1][y2] - S[x2][y1 - 1] + S[x1 - 1][y1 - 1];
```

### 4.3 一维差分

C++

```
// 核心操作：给区间 [l, r] 内的每个数加上 c
void insert(int l, int r, int c) {
    b[l] += c;
    b[r + 1] -= c;
}
// 原数组 a 可以看作是差分数组 b 多次进行 insert(i, i, a[i]) 操作的结果
```

### 4.4 二维差分

C++

```
// 核心操作：给以(x1, y1)为左上角，(x2, y2)为右下角的子矩阵中的所有元素加上 c
void insert(int x1, int y1, int x2, int y2, int c) {
    b[x1][y1] += c;
    b[x2 + 1][y1] -= c;
    b[x1][y2 + 1] -= c;
    b[x2 + 1][y2 + 1] += c;
}
```

### 5.2 离散化

适用于值域跨度大但实际使用元素稀疏的场景。需要对 `vector` 排序并去重。

C++

```
vector<int> alls; // 存储所有待离散化的值
sort(alls.begin(), alls.end()); // 将所有值排序
alls.erase(unique(alls.begin(), alls.end()), alls.end()); // 去掉重复元素

// 二分求出x对应的离散化的值 (下标从 1 开始)
int find(int x) {
    int l = 0, r = alls.size() - 1;
    while (l < r) {
        int mid = l + r >> 1;
        if (alls[mid] >= x) r = mid;
        else l = mid + 1;
    }
    return r + 1; // 映射到 1, 2, ...n
}
```

### 5.3 区间合并

将所有有交集的区间合并。

C++

```
// PII 是 pair<int, int> 的别名，存储区间的左右端点
typedef pair<int, int> PII;

void merge(vector<PII> &segs) {
    vector<PII> res;
    sort(segs.begin(), segs.end()); // 优先按左端点排序

    int st = -2e9, ed = -2e9; // 设定一个初始的不可能存在的区间
    for (auto seg : segs) {
        if (ed < seg.first) {
            if (st != -2e9) res.push_back({st, ed});
            st = seg.first, ed = seg.second;
        }
        else ed = max(ed, seg.second); // 有交集，更新右端点
    }
    if (st != -2e9) res.push_back({st, ed}); // 加上最后一个区间

    segs = res;
}
```

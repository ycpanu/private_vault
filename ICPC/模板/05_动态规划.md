## 1. 背包问题 (Knapsack Problem)

_背包问题是所有 DP 的基础，必须把一维优化的代码刻在肌肉里，且绝对不能把循环写反。_

### 1.1 01 背包问题

**特征**：每件物品最多只能用 1 次。

**核心陷阱**：一维空间优化下，体积 `j` 必须**从大到小**逆序遍历，防止当前物品被重复放入。

C++

```
int f[N]; // f[j] 表示背包容量为 j 时的最大价值

for (int i = 1; i <= n; i ++ ) {            // 枚举前 i 个物品
    for (int j = m; j >= v[i]; j -- ) {     // 逆序枚举体积，下限是当前物品体积 v[i]
        f[j] = max(f[j], f[j - v[i]] + w[i]);
    }
}
// 最终答案是 f[m]
```

### 1.2 完全背包问题

**特征**：每件物品有无限个，可以重复使用。

**核心对比**：代码与 01 背包极其相似，唯独体积 `j` 必须**从小到大**正序遍历。

C++

```
for (int i = 1; i <= n; i ++ ) {
    for (int j = v[i]; j <= m; j ++ ) {     // 正序枚举体积
        f[j] = max(f[j], f[j - v[i]] + w[i]);
    }
}
```

### 1.3 多重背包问题 (二进制优化版)

**特征**：第 `i` 件物品最多有 `s[i]` 个。直接展开成 01 背包会超时，需要用二进制拆分优化（比如把 13 个物品拆成 1, 2, 4, 6 这 4 个独立的物品）。

C++

```
int v[N], w[N]; // N 需要开大，通常是原物品数 * log(S)
int cnt = 0;    // 拆分后的总物品数

// 1. 二进制拆分打包
for (int i = 1; i <= n; i ++ ) {
    int a, b, s;
    cin >> a >> b >> s; // 体积、价值、数量
    int k = 1;
    while (k <= s) {
        cnt ++ ;
        v[cnt] = a * k;
        w[cnt] = b * k;
        s -= k;
        k *= 2;
    }
    if (s > 0) {
        cnt ++ ;
        v[cnt] = a * s;
        w[cnt] = b * s;
    }
}

// 2. 对这 cnt 个物品做普通的 01 背包
for (int i = 1; i <= cnt; i ++ )
    for (int j = m; j >= v[i]; j -- )
        f[j] = max(f[j], f[j - v[i]] + w[i]);
```

### 1.4 分组背包问题

**特征**：物品被划分为若干组，**每一组内最多只能选一件物品**。

**核心结构**：三层循环。**先遍历组，再遍历体积（逆序），最后遍历组内的物品。**

C++

```
for (int i = 1; i <= n; i ++ ) {            // 1. 枚举每一组
    for (int j = m; j >= 0; j -- ) {        // 2. 逆序枚举体积
        for (int k = 0; k < s[i]; k ++ ) {  // 3. 枚举这一组内的所有物品选择
            if (v[i][k] <= j)
                f[j] = max(f[j], f[j - v[i][k]] + w[i][k]);
        }
    }
}
```

## 2. 线性 DP (Linear DP)

_状态转移沿着一条线（通常是数组下标）进行。_

### 2.1 最长上升子序列 (LIS)

**时间复杂度**：$O(N^2)$。

**状态表示**：`f[i]` 表示以 `a[i]` 结尾的所有严格上升子序列的长度的最大值。

C++

```
int a[N], f[N];
int res = 0;

for (int i = 1; i <= n; i ++ ) {
    f[i] = 1; // 只有 a[i] 一个数的情况
    for (int j = 1; j < i; j ++ ) {
        if (a[j] < a[i]) {
            f[i] = max(f[i], f[j] + 1);
        }
    }
    res = max(res, f[i]);
}
```

_(注：如果题目数据量达到 $10^5$，需要用贪心 + 二分优化到 $O(N \log N)$，这里仅列出核心 DP 版)_

### 2.2 最长公共子序列 (LCS)

**状态表示**：`f[i][j]` 表示字符串 `A` 的前 `i` 个字母和字符串 `B` 的前 `j` 个字母的最长公共子序列长度。

C++

```
char a[N], b[N];
int f[N][N];

for (int i = 1; i <= n; i ++ ) {
    for (int j = 1; j <= m; j ++ ) {
        f[i][j] = max(f[i - 1][j], f[i][j - 1]);
        if (a[i] == b[j]) {
            f[i][j] = max(f[i][j], f[i - 1][j - 1] + 1);
        }
    }
}
// 答案为 f[n][m]
```

### 2.3 最短编辑距离 (Edit Distance)

**题意**：将字符串 A 变成 B，可进行增、删、改操作。求最少操作次数。

C++

```
char a[N], b[N];
int f[N][N]; // f[i][j] 表示将 a[1~i] 变成 b[1~j] 的最少操作次数

for (int i = 0; i <= n; i ++ ) f[i][0] = i; // a删掉i个字符变成空
for (int j = 0; j <= m; j ++ ) f[0][j] = j; // 空串增加j个字符变成b

for (int i = 1; i <= n; i ++ ) {
    for (int j = 1; j <= m; j ++ ) {
        f[i][j] = min(f[i - 1][j] + 1, f[i][j - 1] + 1); // 删 / 增
        if (a[i] == b[j]) f[i][j] = min(f[i][j], f[i - 1][j - 1]);     // 不操作
        else f[i][j] = min(f[i][j], f[i - 1][j - 1] + 1);              // 替换
    }
}
```

## 3. 区间 DP (Interval DP)

_状态表示涉及一个区间 `[l, r]`。经典代表题是“石子合并”。_

**核心框架**：三层循环。**先枚举区间长度 `len`，再枚举左端点 `i`，最后枚举分割点 `k`。** （一定要严格遵守这个顺序，否则算大区间时小区间还没算出来）

C++

```
int s[N];    // 前缀和数组，用于 O(1) 计算合并一堆石子的代价
int f[N][N]; // f[i][j] 表示合并区间 [i, j] 的最小代价

for (int len = 2; len <= n; len ++ ) {           // 1. 枚举区间长度 (长度为1的代价为0，不用算)
    for (int i = 1; i + len - 1 <= n; i ++ ) {   // 2. 枚举左端点
        int j = i + len - 1;                     // 计算出右端点
        f[i][j] = 1e9;                           // 初始化为无穷大
        for (int k = i; k < j; k ++ ) {          // 3. 枚举分割点
            f[i][j] = min(f[i][j], f[i][k] + f[k + 1][j] + s[j] - s[i - 1]);
        }
    }
}
// 答案为 f[1][n]
```

## 4. 状态压缩 DP (State Compression DP)

_把一个极其庞大的状态集合，用一个二进制整数来表示。常考题：蒙德里安的梦想、最短 Hamilton 路径。_

### 4.1 最短 Hamilton 路径

**题意**：给定一张无向图，求从点 0 到点 n-1，且每个点恰好经过一次的最短路径。

**状态表示**：`f[i][j]` 中，`i` 是一个二进制数，代表当前走过了哪些点；`j` 代表当前停在哪个点。

C++

```
int w[N][N]; // 图的权重矩阵
int f[1 << 20][20];

memset(f, 0x3f, sizeof f);
f[1][0] = 0; // 初始状态：只走过点0 (二进制...0001)，目前在点0，距离为0

for (int i = 0; i < (1 << n); i ++ ) {        // 枚举所有状态 (包含哪些点)
    for (int j = 0; j < n; j ++ ) {           // 枚举当前在哪个点
        if (i >> j & 1) {                     // 如果状态 i 中确实包含点 j
            for (int k = 0; k < n; k ++ ) {   // 枚举上一步停在哪个点
                if ((i - (1 << j)) >> k & 1) { // 核心：如果状态 i 去掉点 j 后，包含点 k
                    f[i][j] = min(f[i][j], f[i - (1 << j)][k] + w[k][j]);
                }
            }
        }
    }
}
// 答案为 f[(1 << n) - 1][n - 1]
```

## 5. 树形 DP 与 记忆化搜索

### 5.1 树形 DP (没有上司的舞会)

**特征**：在树的结构上做 DP，父节点的状态由子节点推导而来。通过 DFS 实现。

C++

```
int h[N], e[N], ne[N], idx; // 链表存树
int happy[N];               // 结点的权值
int f[N][2];                // f[u][0]表示不选结点u，f[u][1]表示选结点u

void dfs(int u) {
    f[u][1] = happy[u];     // 如果选 u，初值带上权值
    f[u][0] = 0;            // 如果不选 u，初值 0

    for (int i = h[u]; i != -1; i = ne[i]) {
        int j = e[i]; // 子节点 j
        dfs(j); // 递归计算子节点
        
        // 核心状态转移
        f[u][0] += max(f[j][0], f[j][1]); // 父亲不选，儿子选不选都行，挑个大的
        f[u][1] += f[j][0];               // 父亲选了，儿子绝对不能选
    }
}
// 主函数中，找到树的根节点 root
// dfs(root);
// 答案为 max(f[root][0], f[root][1]);
```

### 5.2 记忆化搜索 (滑雪)

**特征**：利用递归形式写 DP，算过的值存下来避免重复计算（相当于给纯暴力 DFS 加个备忘录）。

C++

```
int h[N][N]; // 高度矩阵
int f[N][N]; // 状态备忘录：从 (x, y) 出发能滑行的最大距离
int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1};

int dp(int x, int y) {
    if (f[x][y] != -1) return f[x][y]; // 算过了直接返回

    f[x][y] = 1; // 至少能站在原地，距离为1
    for (int i = 0; i < 4; i ++ ) {
        int a = x + dx[i], b = y + dy[i];
        if (a >= 1 && a <= n && b >= 1 && b <= m && h[a][b] < h[x][y]) {
            f[x][y] = max(f[x][y], dp(a, b) + 1); // 递归搜索
        }
    }
    return f[x][y];
}

// 主函数里先把 f 初始化为 -1
// 然后双重循环枚举每个起点，取 dp(i, j) 的最大值
```

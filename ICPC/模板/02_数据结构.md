## 1. 链表 (Linked Lists)

### 1.1 单链表

**常考题型**：极少单独考，99% 用于构建“邻接表”，是后续图论（最短路、树的遍历）存图的基础。

C++

```
// head存储链表头，e[]存储节点的值，ne[]存储节点的next指针，idx表示当前用到了哪个节点
int head, e[N], ne[N], idx;

void init() {
    head = -1;
    idx = 0;
}

// 在链表头插入一个数a
void insert(int a) {
    e[idx] = a;
    ne[idx] = head;
    head = idx ++ ;
}

// 删除头结点
void remove() {
    head = ne[head];
}
```

### 1.2 双链表

**常考题型**：需要在序列中间频繁进行 $O(1)$ 插入和删除操作。经典笔试题：**实现 LRU 缓存淘汰算法**（哈希表 + 双向链表）。

C++

```
// e[]表示节点的值，l[]表示节点的左指针，r[]表示节点的右指针
int e[N], l[N], r[N], idx;

// 初始化：0是左端点，1是右端点。真实插入的节点从 idx = 2 开始
void init() {
    r[0] = 1, l[1] = 0;
    idx = 2;
}

// 在节点 a 的右边插入一个数 x
void insert(int a, int x) {
    e[idx] = x;
    l[idx] = a, r[idx] = r[a];
    l[r[a]] = idx, r[a] = idx ++ ;
}

// 删除节点 a
void remove(int a) {
    l[r[a]] = l[a];
    r[l[a]] = r[a];
}
```

## 2. 栈与队列 (Stacks & Queues)

### 2.1 单调栈 (Monotonic Stack)

**常考题型**：寻找每个数左边（或右边）**第一个比它大/小的数**。

**经典笔试题**：直方图中最大的矩形面积、接雨水问题。

C++

```
// 寻找左边第一个比当前数小的数
int stk[N], tt = 0; // tt代表栈顶

for (int i = 1; i <= n; i ++ ) {
    int x; cin >> x;
    // 如果栈顶元素大于等于当前数，说明它永远不会作为答案输出，直接出栈
    while (tt && stk[tt] >= x) tt -- ; 
    
    if (tt) cout << stk[tt] << ' ';
    else cout << -1 << ' ';
    
    stk[ ++ tt] = x; // 将当前数压栈
}
```

### 2.2 单调队列 (Monotonic Queue)

**常考题型**：求**滑动窗口里的最大值/最小值**。也是 DP 优化（单调队列优化 DP）的常用手段。

C++

```
// 求滑动窗口中的最小值（注意：队列 q 存储的是原数组的下标）
int q[N], hh = 0, tt = -1; // hh队头，tt队尾

for (int i = 0; i < n; i ++ ) {
    // 1. 判断队头是否滑出了窗口 (k为窗口大小)
    if (hh <= tt && i - k + 1 > q[hh]) hh ++ ;
    
    // 2. 维护单调性：如果队尾元素大于当前元素，队尾出队
    while (hh <= tt && a[q[tt]] >= a[i]) tt -- ;
    
    // 3. 将当前元素下标入队
    q[ ++ tt] = i;
    
    // 4. 输出最值 (前提是窗口已完全进入数组)
    if (i >= k - 1) cout << a[q[hh]] << ' ';
}
```

## 3. 字符串与树 (Strings & Trees)

### 3.1 KMP 算法

**常考题型**：线性时间复杂度内完成**字符串模式匹配**（找子串），或者求字符串的**最小循环节**。

C++

```
// s[]是长文本，p[]是模式串，下标均从 1 开始
int ne[N]; // next数组：匹配失败时指针回退的位置

// 1. 求模式串的 next 数组
for (int i = 2, j = 0; i <= m; i ++ ) {
    while (j && p[i] != p[j + 1]) j = ne[j];
    if (p[i] == p[j + 1]) j ++ ;
    ne[i] = j;
}

// 2. 匹配过程
for (int i = 1, j = 0; i <= n; i ++ ) {
    while (j && s[i] != p[j + 1]) j = ne[j];
    if (s[i] == p[j + 1]) j ++ ;
    if (j == m) {
        printf("%d ", i - m); // 匹配成功，输出起始位置
        j = ne[j]; 
    }
}
```

### 3.2 Trie 字典树

**常考题型**：高效存储和**查找字符串前缀/单词频次**。其变种“01 Trie”常用于解决**最大异或和**问题。

C++

```
int son[N][26], cnt[N], idx; // 0号点既是根节点，又是空节点

// 插入一个字符串
void insert(char *str) {
    int p = 0;
    for (int i = 0; str[i]; i ++ ) {
        int u = str[i] - 'a';
        if (!son[p][u]) son[p][u] = ++ idx;
        p = son[p][u];
    }
    cnt[p] ++ ; // 以该节点结尾的单词数量 +1
}

// 查询字符串出现的次数
int query(char *str) {
    int p = 0;
    for (int i = 0; str[i]; i ++ ) {
        int u = str[i] - 'a';
        if (!son[p][u]) return 0;
        p = son[p][u];
    }
    return cnt[p];
}
```

## 4. 并查集与堆 (Union-Find & Heap)

### 4.1 并查集 (Union-Find)

**常考题型**：极速解决**动态连通性问题**（判断两点是否连通、合并两个集合）。也是 Kruskal 最小生成树算法的核心。

C++

```
int p[N]; // 存储每个点的祖宗节点

// 核心：返回x的祖宗节点，并包含路径压缩优化 (平摊复杂度 O(1))
int find(int x) {
    if (p[x] != x) p[x] = find(p[x]);
    return p[x];
}

// 初始化
for (int i = 1; i <= n; i ++ ) p[i] = i;

// 合并 a 和 b 所在的集合
p[find(a)] = find(b);

// 判断是否在同一集合
if (find(a) == find(b)) {/* ... */}
```

### 4.2 堆 (手写模拟)

**常考题型**：动态维护集合中的最值（Top K 问题、合并果子），以及优化 Dijkstra 最短路算法。

**提示**：在不涉及修改任意位置元素时，直接用 STL 的 `priority_queue` 即可。以下为手写版：

C++

```
int h[N], sz; // h[1]是堆顶，x的左儿子是2x, 右儿子是2x+1

void down(int u) {
    int t = u;
    if (u * 2 <= sz && h[u * 2] < h[t]) t = u * 2;
    if (u * 2 + 1 <= sz && h[u * 2 + 1] < h[t]) t = u * 2 + 1;
    if (u != t) {
        swap(h[u], h[t]);
        down(t);
    }
}

void up(int u) {
    while (u / 2 && h[u] < h[u / 2]) {
        swap(h[u], h[u / 2]);
        u >>= 1;
    }
}

// O(N) 极速建堆
for (int i = n / 2; i; i -- ) down(i);
```

## 5. 哈希表 (Hash Tables)

### 5.1 模拟哈希表 (拉链法)

**常考题型**：大范围离散数字的极速映射。能防止面试官/出题人故意构造数据卡爆 STL 的 `unordered_map`。

C++

```
const int N = 100003; // 取大于区间长度的第一个质数
int h[N], e[N], ne[N], idx;

void init() {
    memset(h, -1, sizeof h);
}

void insert(int x) {
    int k = (x % N + N) % N; // 保证 k 为正数
    e[idx] = x;
    ne[idx] = h[k];
    h[k] = idx ++ ;
}

bool find(int x) {
    int k = (x % N + N) % N;
    for (int i = h[k]; i != -1; i = ne[i])
        if (e[i] == x)
            return true;
    return false;
}
```

### 5.2 字符串前缀哈希 (String Hash)

**常考题型**：**降维打击级的神器！** 可以 $O(1)$ 极速判断两个字符串的任意区间子串是否完全相同，直接替代掉很多烧脑的 KMP 题目。

C++

```
typedef unsigned long long ULL; // 溢出相当于自动对 2^64 取模，省去取模操作
const int N = 100010, P = 131;  // 进制数 P 经验值取 131 或 13331，极少冲突

ULL h[N], p[N]; // h[k]存前k个字母的哈希值, p[k]存 P^k

// 预处理
p[0] = 1;
for (int i = 1; i <= n; i ++ ) {
    p[i] = p[i - 1] * P;
    h[i] = h[i - 1] * P + str[i]; // str 下标从 1 开始
}

// 计算子串 str[l ~ r] 的哈希值，复杂度 O(1)
ULL get_hash(int l, int r) {
    return h[r] - h[l - 1] * p[r - l + 1];
}
```

### 6. ST 表 (Sparse Table) - 静态区间极值查询

**适用题型：**

- **核心标志**：题目要求进行**海量**的区间查询（如 $Q \ge 10^5 \sim 10^6$），但**完全没有修改操作**（数组是静态的）。
    
- **适用范围**：必须是“可重复贡献问题”。即区间重叠计算不会影响最终结果的操作。
    
    - **适用**：区间最大值 (`max`)、区间最小值 (`min`)、区间最大公约数 (`gcd`)、按位与 (`&`)、按位或 (`|`)。
        
    - **绝对禁用**：区间求和、区间异或（重叠部分会被算两次导致错误）。
        
- **对比线段树**：如果题目带有“单点修改”或“区间修改”，立刻放弃 ST 表改用线段树。如果纯粹只查不改，ST 表的 $O(1)$ 查询常数吊打线段树的 $O(\log N)$。
    

**核心代码（1-based 下标，带 Log 常数优化）：**

C++

```
#include <vector>
#include <algorithm>
using namespace std;

const int MAXN = 200005; // 根据题意调整，例如 2*10^5
const int LOG = 21;      // 2^21 > 2*10^6，通常 21 足够

int st[MAXN][LOG]; 
int Log2[MAXN];    

// 1. O(N) 预处理 Log 数组 (程序开头调用一次即可)
void init_log(int n) {
    Log2[1] = 0;
    for (int i = 2; i <= n; i++) {
        Log2[i] = Log2[i / 2] + 1;
    }
}

// 2. O(N log N) 建表 (传入大小 n 和原始数组 a)
void build_st(int n, const vector<int>& a) {
    for (int i = 1; i <= n; i++) {
        st[i][0] = a[i];
    }
    
    // ⚠️ 必考避坑点：外层循环必须是长度指数 j，内层才是起点 i
    for (int j = 1; j < LOG; j++) {
        for (int i = 1; i + (1 << j) - 1 <= n; i++) {
            // 依据题意替换 max : min / std::gcd / & / |
            st[i][j] = max(st[i][j - 1], st[i + (1 << (j - 1))][j - 1]);
        }
    }
}

// 3. O(1) 极速查询区间 [L, R]
int query(int L, int R) {
    int k = Log2[R - L + 1];
    // 依据题意替换 max : min / std::gcd / & / |
    return max(st[L][k], st[R - (1 << k) + 1][k]);
}
```

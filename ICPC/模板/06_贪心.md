## 1. 区间问题 (Interval Problems)

_这是贪心算法里考得最多、最容易搞混的一类题。核心在于：到底是按左端点排序，还是按右端点排序？_

事先定义好区间的结构体：

C++

```
struct Range {
    int l, r;
    // 重载小于号，具体按 l 还是 r 排序看题型
    bool operator< (const Range &W)const {
        return r < W.r; // 默认演示按右端点排序
    }
} ranges[N];
```

### 1.1 区间选点 / 最大不相交区间数量

**题意**：给定 $N$ 个区间，最少选几个点能把所有区间都穿透？（或者问：最多能选出几个完全不相交的区间？）

**贪心策略**：按**右端点**从小到大排序。每次选择当前区间的右端点，如果下一个区间的左端点严格大于当前选的点，说明够不着了，必须新加一个点。

C++

```
// 1. 结构体按右端点 r 从小到大排序
sort(ranges, ranges + n);

int res = 0, ed = -2e9; // ed 记录当前选择的点的坐标
for (int i = 0; i < n; i ++ ) {
    if (ranges[i].l > ed) { // 如果当前区间够不着上一个点
        res ++ ;            // 新增一个点
        ed = ranges[i].r;   // 把新点设为当前区间的右端点 (贪心：尽量往右放)
    }
}
// 答案为 res
```

### 1.2 区间分组

**题意**：给定 $N$ 个区间，把它们分到若干个组里，要求每组内的区间不能相交。求最少需要几个组。

**贪心策略**：按**左端点**从小到大排序。用一个小根堆维护所有组中**最靠右的端点**。如果当前区间能放进最小的那个组，就放进去并更新端点；如果连最小的组都放不进去（产生交集了），只能开一个新组。

C++

```
// 1. 结构体按左端点 l 从小到大排序 (注意修改 operator< )
sort(ranges, ranges + n);

priority_queue<int, vector<int>, greater<int>> heap; // 小根堆，存储每个组最右的端点
for (int i = 0; i < n; i ++ ) {
    auto r = ranges[i];
    if (heap.empty() || heap.top() >= r.l) {
        // 如果堆为空，或者堆顶（最早结束的组）都和当前区间有交集，必须开新组
        heap.push(r.r);
    } else {
        // 可以放进堆顶的组里，更新该组的最右端点
        heap.pop();
        heap.push(r.r);
    }
}
// 答案为 heap.size()
```

### 1.3 区间覆盖

**题意**：给定 $N$ 个区间和一个目标线段 `[st, ed]`，求最少选几个区间能把目标线段完全覆盖。

**贪心策略**：按**左端点**从小到大排序。在所有能覆盖当前 `st` 的区间中，挑一个**右端点延伸得最远**的。

C++

```
// 1. 结构体按左端点 l 从小到大排序
sort(ranges, ranges + n);

int res = 0;
bool success = false;
for (int i = 0; i < n; i ++ ) {
    int j = i, max_r = -2e9;
    // 在所有左端点 <= st 的区间中，找一个右端点最大的
    while (j < n && ranges[j].l <= st) {
        max_r = max(max_r, ranges[j].r);
        j ++ ;
    }
    
    if (max_r < st) { // 如果最大的右端点连当前的 st 都覆盖不到，说明中间断开了
        res = -1;
        break;
    }
    
    res ++ ;
    if (max_r >= ed) { // 已经完全覆盖目标线段
        success = true;
        break;
    }
    st = max_r; // 更新下一步需要覆盖的起点
    i = j - 1;  // 双指针优化：直接跳过已经处理过的区间
}

if (!success) res = -1;
// 答案为 res
```

## 2. 哈夫曼树 (Huffman Tree)

### 2.1 合并果子

**题意**：每次只能合并两堆果子，消耗的体力为这两堆果子重量之和。求把所有果子合并成一堆的最少体力。

**贪心策略**：每次挑**最轻**的两堆合并。使用小根堆（优先队列）极速实现。

C++

```
priority_queue<int, vector<int>, greater<int>> heap;

// 将所有果子丢进小根堆
for (int i = 0; i < n; i ++ ) {
    int x; cin >> x;
    heap.push(x);
}

int res = 0;
while (heap.size() > 1) { // 只要堆里还有2堆以上
    int a = heap.top(); heap.pop();
    int b = heap.top(); heap.pop();
    res += a + b;
    heap.push(a + b); // 合并后放回堆里
}
// 答案为 res
```

## 3. 排序不等式 (Sorting Inequalities)

### 3.1 排队打水

**题意**：$N$ 个人排队打水，每个人打水时间不同，如何安排顺序使得所有人等待的时间总和最小？

**贪心策略**：让打水快的人先打。直接**从小到大排序**即可。

C++

```
int t[N]; // 存储每个人的打水时间

sort(t, t + n);

long long res = 0;
for (int i = 0; i < n; i ++ ) {
    // 第 i 个人打水时，后面有 (n - i - 1) 个人在等他
    res += t[i] * (n - i - 1); 
}
// 答案为 res
```

## 4. 绝对值不等式 (Absolute Value Inequalities)

### 4.1 货仓选址

**题意**：数轴上有 $N$ 家商店，要求建一个货仓，使得所有商店到货仓的距离之和最小。

**贪心策略**：将货仓建在所有商店坐标的**中位数**处（如果有偶数个，中间两个任意一个都行）。

C++

```
int a[N]; // 存储商店坐标

sort(a, a + n); // 必须先排序

int res = 0;
int mid = a[n / 2]; // 找到中位数
for (int i = 0; i < n; i ++ ) {
    res += abs(a[i] - mid); // 累加绝对值距离
}
// 答案为 res
```

## 5. 推公式 (Formula Derivation)

_这类题目通常看起来很唬人，但只要敢于列出相邻两项交换的数学公式，就能发现单调性。_

### 5.1 耍杂技的牛

**题意**：牛叠罗汉，每头牛有重量 $W$ 和强壮程度 $S$。一头牛的危险值 = 它上面的所有牛的重量总和 - 它自己的强壮程度。求如何排列使危险值的最大值最小。

**贪心策略**：按照 $W + S$ 的总和**从小到大排序**，越重的且越壮的牛放在越底下。

C++

```
typedef pair<int, int> PII;
PII cows[N]; // first存 w+s (方便默认按w+s排序)，second存 w

for (int i = 0; i < n; i ++ ) {
    int w, s; cin >> w >> s;
    cows[i] = {w + s, w};
}

sort(cows, cows + n); // 按 W + S 升序排序

int res = -2e9, sum = 0; // sum记录当前牛上面的总重量
for (int i = 0; i < n; i ++ ) {
    int w = cows[i].second, s = cows[i].first - w;
    res = max(res, sum - s); // 危险值 = sum - s
    sum += w; // 为下一头牛累加重量
}
// 答案为 res
```

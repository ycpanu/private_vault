
## 1. 质数 (Primes)

### 1.1 试除法判定质数

**时间复杂度**：$O(\sqrt{N})$

**细节**：循环条件务必写 `i <= n / i`，防止 `i * i` 溢出，也比 `i <= sqrt(n)` 跑得快。

C++

```
bool is_prime(int n) {
    if (n < 2) return false;
    for (int i = 2; i <= n / i; i ++ )
        if (n % i == 0)
            return false;
    return true;
}
```

### 1.2 试除法分解质因数

**时间复杂度**：$O(\sqrt{N})$

**应用**：求一个数的所有质因数及其指数。

C++

```
void divide(int n) {
    for (int i = 2; i <= n / i; i ++ )
        if (n % i == 0) {
            int s = 0;
            while (n % i == 0) n /= i, s ++ ;
            cout << i << ' ' << s << endl; // 输出质因数 i 和它的指数 s
        }
    if (n > 1) cout << n << ' ' << 1 << endl; // 特判：如果 n 还有大于 sqrt(n) 的质因子
    cout << endl;
}
```

### 1.3 线性筛质数 (极度高频)

**时间复杂度**：$O(N)$

**应用**：快速求出 $1 \sim N$ 范围内的所有质数。核心思想是**每个合数只会被它的最小质因子筛掉**。

C++

```
int primes[N], cnt; // primes[] 存储所有质数
bool st[N];         // st[x] 存储 x 是否被筛掉（是否是合数）

void get_primes(int n) {
    for (int i = 2; i <= n; i ++ ) {
        if (!st[i]) primes[cnt ++ ] = i;
        for (int j = 0; primes[j] <= n / i; j ++ ) {
            st[primes[j] * i] = true; // 用最小质因子去筛合数
            if (i % primes[j] == 0) break; // 核心：如果 primes[j] 已经是 i 的质因子了，马上停止
        }
    }
}
```

## 2. 约数 (Divisors)

### 2.1 试除法求所有约数

**时间复杂度**：$O(\sqrt{N})$

C++

```
vector<int> get_divisors(int n) {
    vector<int> res;
    for (int i = 1; i <= n / i; i ++ )
        if (n % i == 0) {
            res.push_back(i);
            if (i != n / i) res.push_back(n / i); // 把另一个约数也加进来
        }
    sort(res.begin(), res.end());
    return res;
}
```

### 2.2 最大公约数 (欧几里得算法)

**极其重要，一行代码搞定。**

C++

```
int gcd(int a, int b) {
    return b ? gcd(b, a % b) : a;
}
// 求最小公倍数 (LCM) 的公式：a / gcd(a, b) * b 
// 注意先除后乘，防止 a * b 溢出 int
```

## 3. 欧拉函数 (Euler's Totient Function)

**定义**：$1 \sim N$ 中与 $N$ 互质的数的个数。

### 3.1 公式法求欧拉函数

**时间复杂度**：$O(\sqrt{N})$

C++

```
int phi(int x) {
    int res = x;
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0) {
            res = res / i * (i - 1); // 公式推导结果
            while (x % i == 0) x /= i;
        }
    if (x > 1) res = res / x * (x - 1);
    return res;
}
```

### 3.2 筛法求欧拉函数

**时间复杂度**：$O(N)$

**应用**：求 $1 \sim N$ 中所有数的欧拉函数之和。依托于线性筛框架。

C++

```
int primes[N], cnt;
int euler[N]; // 存储每个数的欧拉函数
bool st[N];

void get_eulers(int n) {
    euler[1] = 1;
    for (int i = 2; i <= n; i ++ ) {
        if (!st[i]) {
            primes[cnt ++ ] = i;
            euler[i] = i - 1; // 质数的欧拉函数是它本身减一
        }
        for (int j = 0; primes[j] <= n / i; j ++ ) {
            int t = primes[j] * i;
            st[t] = true;
            if (i % primes[j] == 0) {
                euler[t] = euler[i] * primes[j];
                break;
            }
            euler[t] = euler[i] * (primes[j] - 1);
        }
    }
}
```

## 4. 快速幂与乘法逆元

### 4.1 快速幂

**时间复杂度**：$O(\log K)$

**应用**：求 $a^k \pmod p$ 的值。

C++

```
typedef long long LL;

int qmi(int a, int k, int p) {
    int res = 1 % p; // % p 是为了防止 k=0 且 p=1 的极端情况
    while (k) {
        if (k & 1) res = (LL)res * a % p; // 如果二进制最低位是1
        a = (LL)a * a % p;                // 自身平方，基数倍增
        k >>= 1;                          // 右移一位
    }
    return res;
}
```

### 4.2 乘法逆元 (利用费马小定理)

**应用**：如果题目要求 $(A / B) \pmod p$，因为取模运算不能直接除，你需要把它变成 $(A \times B^{-1}) \pmod p$。这里的 $B^{-1}$ 就是乘法逆元。

**条件**：$p$ 必须是质数，且 $B$ 与 $p$ 互质。

C++

```
// 根据费马小定理，b 的乘法逆元就是 b^(p-2) % p
int inverse = qmi(b, p - 2, p);

// 如果题目说“无解”，条件是 a 是 p 的倍数 (即 a % p == 0)
```

## 5. 扩展欧几里得 (ExGcd)

### 5.1 扩展欧几里得算法

**应用**：求出二元一次方程 $ax + by = \gcd(a, b)$ 的一组整数解。

C++

```
// 返回 a 和 b 的最大公约数，并且将引用参数 x, y 赋值为方程的解
int exgcd(int a, int b, int &x, int &y) {
    if (!b) {
        x = 1, y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x); // 注意这里 y 和 x 的位置互换了
    y -= (a / b) * x;
    return d;
}
```

## 6. 组合数学 (Combinatorics)

### 6.1 递推法求组合数 (适用于 $a, b \le 2000$)

**核心**：利用公式 $C_a^b = C_{a-1}^b + C_{a-1}^{b-1}$。这其实是一个类似杨辉三角的 DP 过程。

C++

```
int c[N][N];
const int MOD = 1e9 + 7;

void init() {
    for (int i = 0; i < N; i ++ )
        for (int j = 0; j <= i; j ++ )
            if (!j) c[i][j] = 1;
            else c[i][j] = (c[i - 1][j] + c[i - 1][j - 1]) % MOD;
}
// 使用时直接 O(1) 查表：c[a][b]
```

### 6.2 预处理阶乘求组合数 (适用于 $a, b \le 10^5$)

**核心**：利用公式 $C_a^b = \frac{a!}{b!(a-b)!}$。预处理阶乘和阶乘的逆元。

C++

```
typedef long long LL;
const int MOD = 1e9 + 7;
int fact[N], infact[N]; // fact存阶乘，infact存阶乘的逆元

// 必须复用之前的快速幂求逆元
int qmi(int a, int k, int p) {/*...*/}

void init() {
    fact[0] = infact[0] = 1;
    for (int i = 1; i < N; i ++ ) {
        fact[i] = (LL)fact[i - 1] * i % MOD;
        infact[i] = (LL)infact[i - 1] * qmi(i, MOD - 2, MOD) % MOD;
    }
}
// 使用时直接算：(LL)fact[a] * infact[b] % MOD * infact[a - b] % MOD
```

## 7. 博弈论 (Game Theory)

### 7.1 Nim 游戏

**常考题型**：有 $N$ 堆石子，每次能从一堆中拿走任意数量的石子，不能拿的人输。判断先手必胜还是必败。

**结论**：如果所有石子数量的**异或和**不为 0，则先手必胜；否则先手必败。

C++

```
int res = 0;
for (int i = 0; i < n; i ++ ) {
    int x;
    cin >> x;
    res ^= x; // 全部异或起来
}
if (res) puts("Yes"); // 先手必胜
else puts("No");      // 先手必败
```

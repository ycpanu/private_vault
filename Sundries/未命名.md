# 实验3：使用Selenium进行自动化功能测试

## 一、 测试环境
* **操作系统**：Windows (请根据实际情况修改)
* **开发与测试工具**：IntelliJ IDEA, Maven
* **测试框架**：JUnit 5, Selenium WebDriver (Java API)
* **浏览器及驱动**：Google Chrome 及对应版本的 ChromeDriver

## 二、 被测系统简介
本次测试对象选择了专门用于自动化测试练习的 Web 应用 Sauce Demo (https://www.saucedemo.com/)[cite: 1]。该系统是一个典型的电商网站示例，包含了标准的用户登录、商品列表浏览、购物车管理以及结账全流程，适合用于验证 UI 自动化脚本的各项功能。

## 三、 测试目标
1. 验证系统登录页面的核心逻辑（包含合法用户登录、密码错误拦截、黑名单用户锁定提示）[cite: 1]。
2. 验证商品列表页面的核心交互功能（商品添加至购物车、购物车动态角标数字更新）[cite: 1]。
3. 通过页面工厂模式（POM）实现测试脚本与页面元素的分离，提升自动化测试代码的可维护性[cite: 1]。

## 四、 测试功能点与测试用例
针对登录页和商品页，共设计并实现了以下 5 个自动化测试用例[cite: 1]：

| 用例编号 | 所属页面 | 测试功能点 | 输入/前置操作 | 预期结果 | 定位方式示例 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC_01** | 登录页 | 正确登录跳转 | 输入账号 `standard_user`，密码 `secret_sauce`，点击登录 | 成功跳转至商品列表页，页面左上角显示 "Products" 标题 | `id`, `name` |
| **TC_02** | 登录页 | 密码错误拦截 | 输入账号 `standard_user`，密码 `wrong_pass`，点击登录 | 登录被拦截，页面显示提示 "Username and password do not match" | `cssSelector` |
| **TC_03** | 登录页 | 锁定用户拦截 | 输入账号 `locked_out_user`，密码 `secret_sauce`，点击登录 | 登录被拦截，页面显示提示 "Sorry, this user has been locked out" | `cssSelector` |
| **TC_04** | 商品页 | 动态添加购物车 | 正确登录后，点击第一个商品背包的 "Add to cart" 按钮 | 按钮文本由 "Add to cart" 动态更新为 "Remove" | `xpath` |
| **TC_05** | 商品页 | 购物车角标更新 | 正确登录后，点击第一个商品背包的 "Add to cart" 按钮 | 页面右上角购物车图标出现红色角标，并显示数字 "1" | `cssSelector` |

### 2. 页面对象类：登录页 (`src/main/java/LoginPage.java`)
```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.support.FindBy;
import org.openqa.selenium.support.PageFactory;

public class LoginPage {
    WebDriver driver;

    // 定位方式 1: 使用 id 定位
    @FindBy(id = "user-name")
    WebElement usernameField;

    @FindBy(id = "password")
    WebElement passwordField;

    // 定位方式 2: 使用 name 定位
    @FindBy(name = "login-button")
    WebElement loginButton;

    // 定位方式 3: 使用 cssSelector 定位
    @FindBy(css = "[data-test='error']")
    WebElement errorMessage;

    public LoginPage(WebDriver driver) {
        this.driver = driver;
        // 初始化页面元素
        PageFactory.initElements(driver, this);
    }

    public void login(String username, String password) {
        usernameField.clear();
        usernameField.sendKeys(username);
        passwordField.clear();
        passwordField.sendKeys(password);
        loginButton.click();
    }

    public String getErrorMessage() {
        return errorMessage.getText();
    }
}
```

### 3. 页面对象类：商品页 (`src/main/java/InventoryPage.java`)
```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.WebElement;
import org.openqa.selenium.support.FindBy;
import org.openqa.selenium.support.PageFactory;

public class InventoryPage {
    WebDriver driver;

    @FindBy(css = ".title")
    WebElement pageTitle;

    // 定位方式 4: 使用 xpath 定位
    @FindBy(xpath = "//button[@id='add-to-cart-sauce-labs-backpack']")
    WebElement addBackpackToCartButton;

    @FindBy(xpath = "//button[@id='remove-sauce-labs-backpack']")
    WebElement removeBackpackButton;

    @FindBy(css = ".shopping_cart_badge")
    WebElement cartBadge;

    public InventoryPage(WebDriver driver) {
        this.driver = driver;
        PageFactory.initElements(driver, this);
    }

    public String getPageTitle() {
        return pageTitle.getText();
    }

    public void clickAddBackpackToCart() {
        addBackpackToCartButton.click();
    }

    public String getRemoveButtonText() {
        return removeBackpackButton.getText();
    }

    public String getCartBadgeText() {
        return cartBadge.getText();
    }
}
```

### 4. 测试执行类 (`src/test/java/SauceDemoTest.java`)
```java
import org.junit.jupiter.api.AfterEach;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import java.time.Duration;
import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertTrue;

public class SauceDemoTest {
    WebDriver driver;
    LoginPage loginPage;
    InventoryPage inventoryPage;

    @BeforeEach
    public void setUp() {
        // 启动 Chrome 浏览器
        driver = new ChromeDriver();
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(5));
        driver.get("[https://www.saucedemo.com/](https://www.saucedemo.com/)");
        
        // 实例化页面对象
        loginPage = new LoginPage(driver);
        inventoryPage = new InventoryPage(driver);
    }

    @AfterEach
    public void tearDown() {
        if (driver != null) {
            driver.quit();
        }
    }

    // TC_01：测试正常登录跳转
    @Test
    public void testLoginSuccess() {
        loginPage.login("standard_user", "secret_sauce");
        assertEquals("Products", inventoryPage.getPageTitle());
    }

    // TC_02：测试密码错误拦截
    @Test
    public void testLoginFailure() {
        loginPage.login("standard_user", "wrong_password");
        assertTrue(loginPage.getErrorMessage().contains("Username and password do not match"));
    }

    // TC_03：测试锁定用户拦截
    @Test
    public void testLockedOutUser() {
        loginPage.login("locked_out_user", "secret_sauce");
        assertTrue(loginPage.getErrorMessage().contains("Sorry, this user has been locked out"));
    }

    // TC_04：测试添加商品到购物车，按钮文本变化
    @Test
    public void testAddToCart() {
        loginPage.login("standard_user", "secret_sauce");
        inventoryPage.clickAddBackpackToCart();
        assertEquals("Remove", inventoryPage.getRemoveButtonText());
    }

    // TC_05：测试添加商品后，右上角购物车角标更新
    @Test
    public void testCartBadgeUpdates() {
        loginPage.login("standard_user", "secret_sauce");
        inventoryPage.clickAddBackpackToCart();
        assertEquals("1", inventoryPage.getCartBadgeText());
    }
}
```

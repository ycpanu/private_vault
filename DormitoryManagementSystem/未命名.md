## 一、项目背景与意义

随着高校规模的不断扩大和学生人数的持续增长，传统的宿舍管理模式已无法满足现代化管理的需求。我们开发的这套学生宿舍管理系统旨在解决以下几个问题：

1. **提高管理效率**：通过信息化手段减少人工操作，降低出错率
2. **优化资源配置**：实现宿舍资源的动态调配和合理利用
3. **改善用户体验**：为学生、宿舍管理员、系统管理员提供便捷的操作界面
4. **数据统计分析**：为决策提供可靠的数据支撑

## 二、系统架构与技术选型

### 技术架构

- **后端技术栈**：Spring Boot + MyBatis-Plus + MySQL
- **前端技术栈**：Vue.js + Element Plus
- **开发语言**：Java + JavaScript
- **数据库**：MySQL 8.0
- **开发工具**：IDEA、VS Code、Postman

### 为什么选择这样的技术架构？

1. **Spring Boot**：提供了快速开发的能力，简化了配置过程
2. **MyBatis-Plus**：增强了MyBatis的功能，提供了强大的CRUD操作能力
3. **Vue.js**：轻量级前端框架，组件化开发，易于维护
4. **Element Plus**：成熟的UI组件库，提供了丰富的界面组件

## 三、系统功能模块

### 1. 用户角色管理

- **学生用户**：可查看个人信息、宿舍信息、申请调宿、报修等
- **宿舍管理员**：管理所负责宿舍楼的学生信息、处理报修申请等
- **系统管理员**：管理所有用户信息、发布公告、统计数据分析等

### 2. 核心功能模块

- **宿舍分配管理**：实现学生入住、调宿、退宿等操作
- **报修管理**：在线报修申请、进度跟踪、完成确认
- **访客管理**：访客登记、访问记录、统计分析
- **请假管理**：请假申请、审批流程、状态跟踪
- **通知公告**：信息发布、推送、查阅历史

### 3. 数据统计与分析

- 学生人数统计
- 住宿情况分析
- 报修数据统计
- 空宿舍数量统计

## 四、数据库设计

我们设计了8张核心数据表：

1. **student表**：学生基本信息
2. **admin表**：系统管理员信息
3. **dorm_manager表**：宿舍管理员信息
4. **dorm_build表**：宿舍楼信息
5. **dorm_room表**：宿舍房间信息（包含床位分配）
6. **repair表**：报修记录
7. **visitor表**：访客记录
8. **notice表**：通知公告
9. **adjust_room表**：调宿申请记录

这些表之间建立了合理的关系，确保数据的一致性和完整性。

## 五、关键技术实现

### 1. 床位管理算法

我们实现了智能床位分配算法，能够自动检测床位占用情况，防止重复分配，确保每个床位只能被一个学生占用。

### 2. 文件上传与处理

实现了学生头像上传功能，支持图片上传并转换为Base64格式进行传输和存储。

### 3. 分页查询

使用MyBatis-Plus的分页插件，实现了大数据量的高效分页查询。

### 4. 统一响应格式

设计了统一的响应类(R)，确保前后端数据交互的一致性。

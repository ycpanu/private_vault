#### 模板一：寻找“满足条件的第一个/最小值”（往左逼近）

**场景：** 找第一个大于等于 x 的位置、找满足条件的最左侧边界。

Python
```
def binary_search_left(l, r):
    while l < r:
        mid = (l + r) // 2  # 【正常取中】
        if check(mid): 
            r = mid         # 答案在左半边（包含 mid），向左收缩
        else:
            l = mid + 1     # 答案在右半边（不含 mid）
    return l  # 循环结束时 l == r
```

#### 模板二：寻找“满足条件的最后一个/最大值”（往右逼近）

**场景：** 找最后一个小于等于 x 的位置、找满足条件的最右侧边界。

Python

```
def binary_search_right(l, r):
    while l < r:
        mid = (l + r + 1) // 2  # 【高危预警：必须 +1 ！】
        if check(mid):
            l = mid             # 答案在右半边（包含 mid），向右收缩
        else:
            r = mid - 1         # 答案在左半边（不含 mid）
    return l  # 循环结束时 l == r
```
- 只要代码里出现了 **`l = mid`**，计算 mid 时就**必须写 `+ 1`**，即 `mid = (l + r + 1) // 2`。
    
- 只要代码里写的是 **`r = mid`**，计算 mid 时**千万不要 `+ 1`**，即 `mid = (l + r) // 2`。

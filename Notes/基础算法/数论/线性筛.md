# 线性筛：预处理范围内的最小素因子（SPF)

- **代码模板** ：
	```
	const int MAXN = 10000005;
	int spf[MAXN]; // 记录每个数的最小素因子 
	vector<int> primes; // 欧拉筛预处理 10^7 以内的最小素因子 
	void sieve() { 
		for (int i = 2; i < MAXN; i++) {
			if (spf[i] == 0) { 
				spf[i] = i; 
				primes.push_back(i); 
			} 
			for (int p : primes) { 
				if (p * i >= MAXN) break; 
				spf[p * i] = p; 
				if (i % p == 0) break; // 保证线性复杂度 
			}
		} 
	}
	```

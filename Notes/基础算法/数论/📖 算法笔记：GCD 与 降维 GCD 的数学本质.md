## 💡 核心总结
* **普通 `gcd`** 处理的是**倍数关系**（算术维度），底层逻辑是**减法/取模**。
* **降维 `gcd_sub`** 处理的是**幂次关系**（指数维度），底层逻辑是**除法**。它是套着除法外衣的指数辗转相除法。

---

## 一、 普通的最大公约数：`gcd(a, b)`
**适用场景**：等差数列求公差、周期重叠求最大公共周期等（处理加减乘除）。

* **数学模型**：求两个数 $a$ 和 $b$ 的最大公因数 $g$。
    设 $a = p \cdot g$，$b = q \cdot g$。
* **操作降维（核心原理）**：
    两数相减，公因数 $g$ 不变：$a - b = (p-q) \cdot g$。
    为了加速减法，在代码中退化为**取模（求余）**。
* **Python 代码模板**：
    ```python
    def gcd(a, b):
        return a if b == 0 else gcd(b, a % b)
    ```
* **停止边界**：当 `b == 0` 时，说明减完了，此时的 `a` 就是最大公约数。
* **经典例子**：$\gcd(12, 8) = 4$（12 和 8 都是 4 的倍数）。

---

## 二、 降维最大公约底数：`gcd_sub(a, b)`
**适用场景**：等比数列抽样求最大公比、已知多个同底数幂求底数（处理乘方）。

* **数学模型**：求两个同底数幂 $A$ 和 $B$ 的最大公共底数 $Z$。
    设 $A = Z^p$，$B = Z^q$（此时我们要找的是底数 $Z$，要求指数 $p, q$ 互质）。
* **操作降维（核心原理）**：
    根据指数定律，**同底数幂相除，底数不变，指数相减**！
    $$\frac{A}{B} = \frac{Z^p}{Z^q} = Z^{p-q}$$
    即：代码里的**相除**，在指数的维度上实际上就是在做**相减**。
* **Python 代码模板**：
    ```python
    def gcd_sub(a, b):
        if a < b:
            a, b = b, a
        if b == 1:
            return a
        return gcd_sub(b, a // b)
    ```
* **停止边界**：当 `b == 1` 时，说明在指数维度上“减到了 $0$”（因为 $Z^0 = 1$），此时的 `a` 就是我们要找的最大公约底数。
* **经典例子**：已知数列项为 $32$ 和 $8$。
    $32 = 2^5$，$8 = 2^3$。
    `gcd_sub(32, 8)` 会通过连续除法（$32\div8=4$, $8\div4=2$, $4\div2=2$），最终扒出底数 $2$。

---

## 📊 三、 极简对比速查表

| 对比维度 | 传统 `gcd(a, b)` | 降维 `gcd_sub(a, b)` |
| :--- | :--- | :--- |
| **解决目标** | 求最大公因数（因子） | 求最大公共底数（基底） |
| **数列应用** | **等差数列**求最大公差 | **等比数列**求最大公比 |
| **数学展开** | $a = p \cdot g, \ b = q \cdot g$ | $A = Z^p, \ B = Z^q$ |
| **核心运算** | **取模 (`a % b`)**<br>本质是加速算术减法 | **整除 (`a // b`)**<br>本质是加速指数减法 |
| **递归终点** | `b == 0` | `b == 1` |
| **测试 (32, 8)**| 返回 $8$ | 返回 $2$ |

**📝 避坑指南：**
在竞赛中，遇到“在未知完整序列中抽样了几个数，求原序列参数”的题目：
不要想当然地用 `min()` 去找最小间隔！**间距的最大公约数**才是唯一的正解。等差用 `gcd`，等比用 `gcd_sub`。

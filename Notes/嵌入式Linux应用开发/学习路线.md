## 二、Linux 系统编程
- 文件 I/O
	- open / read / write / close
	- 标准 I/O 库（fopen / fprintf / fread）
	- 文件描述符与文件表
	- mmap 内存映射 I/O
	- 异步 I/O（AIO）
- 进程管理
	- fork / vfork / clone
	- exec 函数族
	- 孤儿进程与僵尸进程
	- 守护进程（daemon）
	- 进程调度与优先级
- 线程编程
	- pthread 创建与管理
	- 线程同步（互斥锁 / 条件变量 / 读写锁）
	- 线程安全与可重入
	- 线程池设计
- 进程间通信（IPC）
	- 管道（匿名管道 / 命名管道 FIFO）
	- System V IPC（共享内存 / 消息队列 / 信号量）
	- POSIX IPC（消息队列 / 共享内存 / 信号量）
	- Unix Domain Socket
	- D-Bus
- 信号
	- 常用信号（SIGINT / SIGKILL / SIGUSR1）
	- signal / sigaction
	- 信号集与信号屏蔽字
	- 定时器信号（alarm / setitimer / timerfd）
- 网络编程
	- TCP/IP 协议栈基础
	- Socket API（socket / bind / listen / accept / connect）
	- I/O 多路复用（select / poll / epoll）
	- 高并发模型（Reactor / Proactor）
	- 常用协议（HTTP / MQTT / WebSocket）
	- 抓包工具（tcpdump / Wireshark）

## 1. 文件与目录操作

这是日常使用频率最高的一组命令，用于在系统中导航和管理文件。

| **命令**  | **常用示例**                 | **作用说明**                              |
| ------- | ------------------------ | ------------------------------------- |
| `ls`    | `ls -la`                 | 列出目录内容（`-l` 详细信息，`-a` 包含隐藏文件）         |
| `cd`    | `cd /var/log`<br>`cd ..` | 切换工作目录（`..` 代表上一级目录，`~` 代表家目录）        |
| `pwd`   | `pwd`                    | 显示当前所在目录的完整绝对路径                       |
| `mkdir` | `mkdir -p a/b/c`         | 创建目录（`-p` 递归创建多级目录）                   |
| `rm`    | `rm -rf dist/`           | 删除文件或目录（`-r` 递归删除目录，`-f` 强制执行，**慎用**） |
| `cp`    | `cp -r src/ dest/`       | 复制文件或目录（`-r` 用于复制整个目录）                |
| `mv`    | `mv old.txt new.txt`     | 移动文件/目录，也常用于**重命名**                   |
| `touch` | `touch index.html`       | 创建一个空文件，或更新已存在文件的时间戳                  |

## 2. 文件查看与文本搜索

当你需要快速查看日志或在文件中查找特定内容时，这些命令必不可少。

|**命令**|**常用示例**|**作用说明**|
|---|---|---|
|`cat`|`cat config.yaml`|一次性输出文件的全部内容|
|`less`|`less large_log.txt`|分页查看大文件（支持上下翻页和搜索，按 `q` 退出）|
|`tail`|`tail -f app.log`|查看文件末尾内容（`-f` 会**实时滚动**显示新追加的日志）|
|`head`|`head -n 20 file.txt`|查看文件开头的指定行数（默认 10 行）|
|`grep`|`grep -i "error" app.log`|文本搜索（`-i` 忽略大小写，`-v` 排除匹配项）|
|`find`|`find . -name "*.jpg"`|在文件系统中搜索文件（示例为查找当前目录下的所有 jpg）|

## 3. 系统状态与进程管理

用于监控服务器健康状况、排查卡顿或结束无响应的程序。

|**命令**|**常用示例**|**作用说明**|
|---|---|---|
|`top`|`top`|实时显示系统资源使用情况及各个进程的占用（按 `q` 退出）|
|`ps`|`ps aux \| grep node`|查看当前运行的进程快照（常结合 grep 查找特定进程）|
|`kill`|`kill -9 1234`|终止进程（`1234` 为进程PID，`-9` 强制终止）|
|`df`|`df -h`|查看各个磁盘分区的剩余**磁盘空间**（`-h` 以人类可读格式显示）|
|`du`|`du -sh *`|查看当前目录下各个文件/文件夹占用的**大小**|
|`free`|`free -m`|查看系统**内存**（RAM）使用情况（`-m` 以 MB 为单位）|

## 4. 压缩与解压缩

Linux 下最常见的是 `.tar.gz` 格式。

|**命令**|**常用示例**|**作用说明**|
|---|---|---|
|`tar` (解压)|`tar -zxvf file.tar.gz`|解压 `.tar.gz` 文件（**z**=gzip, **x**=extract, **v**=verbose, **f**=file）|
|`tar` (压缩)|`tar -zcvf file.tar.gz ./dir`|将目录打包并压缩为 `.tar.gz` 格式（**c**=create）|
|`zip`|`zip -r data.zip ./data`|将目录压缩为 `.zip` 格式（需要系统安装了 zip）|
|`unzip`|`unzip data.zip`|解压 `.zip` 文件|

## 5. 权限与网络基础

|**命令**|**常用示例**|**作用说明**|
|---|---|---|
|`chmod`|`chmod +x script.sh`|修改文件权限（`+x` 赋予可执行权限，或用数字 `755` 等）|
|`chown`|`chown root:root file`|修改文件或目录的所有者和所属组|
|`ping`|`ping google.com`|测试网络连通性及延迟|
|`curl`|`curl -O http://url/file`|发送网络请求，或从网络下载文件（`-O` 保持原文件名保存）|

> **高效终端快捷键（Pro Tips）：**
> 
> - `Tab` 键：自动补全文件路径或命令（最常用的快捷键）。
>     
> - `Ctrl + C`：强制中断当前正在运行的命令。
>     
> - `Ctrl + L`（或输入 `clear`）：清屏。
>     
> - `Ctrl + R`：进入历史命令搜索模式，输入关键字能快速找到之前敲过的命令。
>     
> - `↑` 上方向键：调出上一条执行过的命令。
